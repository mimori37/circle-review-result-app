# 琉大新サークル設立審査会 リザルト発表アプリ

審査フォーム（Googleフォーム）の回答を集計して、グループごとに本家のリズム天国と同じ順番――**「カバー → ことば（寸評）→ 判定 → 締め」**――で発表するための単一HTMLアプリです。評価はまず「サークル審査係からのことば」として届き、判定はそのあとに大きく出ます。ランキング表示・順位付けはしません（発表順＝出番順）。

## 開き方

`index.html` をダブルクリックしてブラウザで開くだけです。インストール不要（外部ライブラリなし）。URL取得機能を使う場合だけネット接続が必要です。

## 発表の流れ（1グループごと）

1. **カバー**：グループ名＋サークル名だけを表示。判定・数値は出しません
2. **ことば**：「サークル審査係からのことば」のラベルのもと、事前に選んだコメントを1件ずつ大きく表示（最大2〜3件が目安。総評的なコメントは最後に回すのがおすすめです）
3. **判定**：画面が切り替わり、判定語を画面最大級で一発表示。判定ごとに短い効果音が鳴ります（ブラウザの Web Audio API で生成する単純な音色のみ）。「ハイレベル！」のときだけメダル風バッジが添えられます。判定語の下には、事前に入力した「一言キャプション」を1行出せます。平均点は下に小さく添えるだけです
4. **締め**（全グループ終了後）：判定は並べず、「今日の審査会まとめ」の一言＋全サークル名の一覧だけを表示します

## データの取り込み方（3通り）

### A. CSVファイル（基本）

1. Googleフォームの編集画面で「回答」タブを開く
2. スプレッドシートのアイコン（緑）から回答シートを開く（まだ作っていない場合は作成する）
3. スプレッドシートで「ファイル → ダウンロード → カンマ区切り形式（.csv）」を選ぶ

※ フォームの回答画面右上の「︙」メニュー →「回答をダウンロード（.csv）」でも書き出せます。

### B. スプレッドシートの公開CSVリンク（URL取得）

1. 回答スプレッドシートで「ファイル → 共有 → ウェブに公開」を開く
2. 対象シートを選び、形式を「カンマ区切り形式（.csv）」にして公開し、表示されたリンクをコピー
3. アプリの「1-B. URLから取り込む」に貼って「URLから読み込む」

### C. GAS WebアプリのJSONエンドポイント（URL取得）

フォーム回答スプレッドシートに Apps Script を紐づけ、回答をJSONで返す Webアプリとして公開すると、そのURLを貼るだけで取り込めます。手順とサンプルコードは後述の「GASの設定手順」を参照してください。

### 自動更新

「自動更新する」にチェックを入れると、30秒ごとにURLを再取得して新しい回答を取り込みます（手動の「更新」ボタンもあります）。発表の最中に新しい回答が届いた場合は画面を切り替えず、Escで設定画面に戻ったタイミングで反映されます（発表画面の上に「新しい回答が届いています」と表示されます）。

取得に失敗する場合は、公開設定を確認してください（シートの「ウェブに公開」／GASは「全員」アクセスでデプロイ）。ブラウザのセキュリティ制限（CORS）で取得できない環境では、A のCSV方式に切り替えてください。

## 当日の使い方

1. アプリを開き、上のいずれかの方法で回答を取り込む
2. 「列の対応を確認する」で、グループ名／サークル名（任意）／賛成度／良かった点／気になった点の列が合っているか確認（自動で推測されますが、列名が違う場合はプルダウンで直してください）
3. 「集計結果」で平均と判定を発表者だけ事前確認
4. 「発表の順番とサークル名」で ↑↓ ボタンで出番順に並べ替え、サークル名を入力・修正
5. 「届ける『ことば』を選ぶ」で、グループごとに表示するコメントにチェック（初期状態では「良かった点」の先頭3件が選ばれています）。↑↓で順番を調整し、必要なら「判定のあとに添える一言」も入力（「最後のことばを流用」ボタンで、最後に表示することばをそのまま一言にできます）
6. 締め画面の一言を確認して「発表をはじめる」を押す（全画面になります）

CSVがまだ無い状態でも、「サンプルデータで試す」ボタンで全フローを練習できます。

## 発表の操作

| 操作 | 動き |
|---|---|
| クリック / → キー / スペース | 次へ進む（カバー → ことば1件目 → ことば2件目… → 判定 → 次のグループのカバー… → 締め） |
| ← キー | 1つ戻る |
| Esc | 発表を終えて設定画面に戻る（発表中に届いた新着回答があれば、このタイミングで反映されます） |

- ことばが1件も選ばれていないグループは、カバーから判定へ直接進みます
- 判定画面の効果音は、ブラウザの仕様上「発表をはじめる」を押したあとから鳴ります

## 判定バンド（賛成度の平均）

| 平均 | 判定 |
|---|---|
| 4.5 – 5.0 | ハイレベル！ |
| 4.0 – 4.49 | かなりいいかんじ！ |
| 3.0 – 3.99 | 平凡！ |
| 2.0 – 2.99 | あと一歩！ |
| 1.0 – 1.99 | 再チャレンジ！ |

## GASの設定手順（方法Cを使う場合）

### アプリが受け付けるJSON形式

GASのエンドポイントは、次のようなオブジェクトの配列（または `responses` キーの中身がその配列でも可）を返してください。キーは英語でも日本語でも構いません。

```json
[
  {
    "group": "グループ1",
    "circle": "星空観察サークル",
    "score": 5,
    "good": "キャンパスで星を見る発想がロマンチックだった",
    "concern": "活動費の内訳が分かりにくかった"
  },
  {
    "group": "グループ1",
    "circle": "星空観察サークル",
    "score": 4,
    "good": "初心者でも入りやすそう",
    "concern": ""
  }
]
```

| キー（英語） | キー（日本語） | 中身 |
|---|---|---|
| `group` | `グループ名` | 発表を聞いたグループ（必須） |
| `circle` | `サークル名` | サークル名（任意） |
| `score` | `賛成度` | 賛成度（1〜5、数値でも文字列でも可） |
| `good` | `良かった点` | 自由記述（任意） |
| `concern` | `気になった点` | 自由記述（任意） |

### サンプルコード

回答スプレッドシートを開き、「拡張機能 → Apps Script」でスクリプトエディタを開いて、以下を貼り付けます。列の位置はヘッダー名（「グループ」「賛成」「良かった」「気になった」を含む列）から自動で探します。サークル名はフォームに列が無い前提で空文字にしています（列がある場合は `circle` の行を同様に書き換えてください）。

```javascript
function doGet() {
  const sheet = SpreadsheetApp.getActiveSpreadsheet().getSheets()[0];
  const values = sheet.getDataRange().getValues();
  const headers = values[0].map(h => String(h));
  const findCol = keyword => headers.findIndex(h => h.includes(keyword));
  const idx = {
    group: findCol('グループ'),
    score: findCol('賛成'),
    good: findCol('良かった'),
    concern: findCol('気になった'),
  };
  const out = [];
  for (let i = 1; i < values.length; i++) {
    const row = values[i];
    if (idx.group < 0 || String(row[idx.group]).trim() === '') continue;
    out.push({
      group: String(row[idx.group]),
      circle: '',
      score: idx.score >= 0 ? row[idx.score] : '',
      good: idx.good >= 0 ? String(row[idx.good]) : '',
      concern: idx.concern >= 0 ? String(row[idx.concern]) : '',
    });
  }
  return ContentService
    .createTextOutput(JSON.stringify(out))
    .setMimeType(ContentService.MimeType.JSON);
}
```

### デプロイ手順

1. スクリプトエディタ右上の「デプロイ → 新しいデプロイ」
2. 種類で「ウェブアプリ」を選択
3. 「次のユーザーとして実行」は「自分」、「アクセスできるユーザー」は **「全員」** にする（これを忘れるとアプリから取得できません）
4. 「デプロイ」を押して表示される WebアプリのURL（`https://script.google.com/macros/s/…/exec`）をコピー
5. アプリの「1-B. URLから取り込む」に貼って「URLから読み込む」

※ コードを変更したときは、新しいデプロイ（またはデプロイの管理から新しいバージョン）をしないと変更が反映されません。

## 注意

- CSVは文字コード UTF-8 前提です（Googleフォーム／スプレッドシートの書き出しは通常 UTF-8 です）。文字化けする場合はスプレッドシート経由で書き出し直してください。
- 賛成度は「5」「5（とても賛成）」「とても賛成」のような表記でも自動で数値化します。
- CSV／ファイルから取り込んだ回答データはブラウザ内だけで処理され、外部に送信されることはありません。URL取得の場合は、指定したURLへ読み取りリクエストのみを行います。
