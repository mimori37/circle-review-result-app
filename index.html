1-B. 回答データをURLから取り込む（リアルタイム）

スプレッドシートを「ウェブに公開」したCSVリンク、または GAS WebアプリのJSONエンドポイントURLを貼ると、ネット経由で回答を取り込めます。設定方法は README を参照してください。

取得に失敗する場合は、公開設定（リンクを知っている全員が閲覧可／GASは「全員」アクセスでデプロイ）を確認してください。それでも難しい場合は、上のCSV方式で取り込めます。

2. 列の対応を確認する

CSVの列名が想定と違う場合は、ここで割り当て直してください。サークル名の列は任意です（無ければ発表順の画面で直接入力できます）。

3. 集計結果（発表者用の確認）

グループサークル名回答数賛成度の平均判定

平均と判定は発表者だけが事前に確認するための表示です。発表画面では数値は主役にせず、ことば（寸評）と判定だけを大きく出します。

4. 発表の順番とサークル名を決める

発表順（出番順）に並べてください。スコア順ではありません。サークル名はここで入力・修正できます。

5. 届ける「ことば」を選ぶ

発表では、判定の前に「サークル審査係からのことば」として、選んだコメントを1件ずつ大きく表示します（最大2〜3件が目安）。チェックで選び、↑↓で順番を変えられます。総評的なコメントは最後に回すのがおすすめです。「判定のあとに添える一言」は、判定画面で判定語の下に1行だけ出ます。

6. 締めの画面と発表開始

全グループの発表が終わったあとの締め画面に出す一言です（判定は並べません）。

発表画面では → キー／クリックで進みます（カバー → ことば → 判定 → 次のグループ…）。Esc でこの画面に戻ります。
